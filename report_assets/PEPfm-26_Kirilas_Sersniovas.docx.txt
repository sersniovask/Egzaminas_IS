[Heading 1] Vehicle silhouette classification
[Normal] Classify a vehicle type from geometric silhouette features. Compare k-nearest neighbours and a nearest-centroid baseline with an SVM, MLP, RBF network or SOM-supported approach. Use repeated stratified cross-validation. Report macro-F1, balanced accuracy and a confusion matrix, and discuss overlapping classes and uncertainty from the small sample.
[Heading 2] Dataset
[Normal] OpenML Vehicle, https://www.openml.org/d/54
[Heading 1] Colloquium deliverable
[Normal] Prepare an implementation plan. Final code and results are not required yet, but the plan must be specific enough for another developer to begin the implementation.
[List Bullet] Formulate the practical problem, technical task and expected value. Identify uncertainties, constraints and the cost of different errors.
[List Bullet] Break the solution into data acquisition, preprocessing, model training, evaluation and use. Define the input and output precisely.
[List Bullet] Present two to four possible intelligent methods and a simple baseline. Justify every method with verified primary sources and provide a DOI or stable link.
[List Bullet] Select the main method and state a testable hypothesis describing when and why it should outperform the baseline.
[List Bullet] Give the main equations or rules of the selected model, explain every variable and map them to planned software modules.
[List Bullet] Define the data split, preprocessing, metrics, ablation, error analysis, computation budget and the main threats to validity before implementation.
[List Bullet] State how AI tools will be used and how citations, equations, code and results will be checked.
[Heading 1] Final examination deliverable
[Normal] Submit a working and reproducible solution together with evidence that makes its performance and limitations possible to assess.
[List Bullet] Implement the data pipeline, the baseline and at least two intelligent methods. For at least one model, connect the equations or rules to a specific part of the code.
[List Bullet] Compare all methods using the same data split and metrics. Do not use the final test set for hyperparameter selection.
[List Bullet] Perform at least one ablation or feature-sensitivity experiment and at least one robustness test involving noise, missing data, time shift or group shift.
[List Bullet] Provide a results table, an appropriate figure and examples of errors. Explain why the selected method did or did not win. A negative result is acceptable when the experiment is correct.
[List Bullet] Provide execution instructions, dependencies, fixed random seeds and one command that reproduces the main experiment. Dataset files need not be submitted when reproducible download instructions are provided.
[List Bullet] Provide an AI-use log containing the most important prompts, accepted and rejected suggestions, and at least two AI errors or unchecked assumptions together with the verification performed.
[List Bullet] During the live defence, explain a selected equation and the corresponding code, run an unseen test supplied by the lecturer and make a small change to the model, metric or preprocessing.
